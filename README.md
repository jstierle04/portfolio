# James — GitHub Pages Portfolio

A static, responsive portfolio website built with plain HTML and CSS.

## Files

- `index.html` — About / landing page
- `resume.html` — Native HTML resume
- `projects.html` — Portfolio with three project sections
- `assets/style.css` — Shared blue visual theme and responsive layout

## Publish with GitHub Pages

1. Create a new GitHub repository. A repository named `portfolio` is fine; a special `USERNAME.github.io` repository is also possible.
2. Upload all files and folders from this directory, preserving the structure.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. GitHub will provide the published site URL.
